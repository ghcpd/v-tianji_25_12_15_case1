# Travel Planner

A small travel planning UI built with Vite + React + TypeScript + Tailwind. Includes unit tests (Vitest) and E2E tests (Playwright).

Commands:

- npm install
- npm run dev (start dev server)
- npm run test:unit (run unit tests)
- npm run test:e2e (run Playwright E2E tests)
- npm run test (run all tests)
