# Travel Planner UI

Simple React + Vite travel planner demo. Includes unit tests with Vitest and E2E tests with Playwright.

Commands:

Install:
```
npm install
npx playwright install
```

Run unit tests:
```
npm run test:unit
```

Run e2e tests:
```
npm run test:e2e
```

Run dev server:
```
npm run dev
```
